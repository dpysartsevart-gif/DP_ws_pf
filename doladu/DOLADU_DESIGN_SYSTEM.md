# DoLadu — дизайн-система для сторінки-порталу

Цей документ описує, **як виглядає сам застосунок**. Усі значення тут
витягнуті з коду, що зібраний в інсталятор 1.0 — `hub_ui.py`, `hub_core.py`,
`hub_fonts.py` і `Wireframecode - Final.html` — а не придумані «схоже».

Мета: сторінка на сайті має читатись як **той самий продукт**, а не як його
презентація. Людина, що бачила скріншот, мусить впізнати ті самі картки, ту
саму типографіку і ті самі кольори станів.

**Джерела правди в репозиторії:**

| що | де |
|---|---|
| фон-сцена (той самий, що в застосунку) | `Wireframecode - Final.html` |
| логотипи й марка | `assets/design/doladu_lockup.svg`, `doladu_mark.svg` |
| шрифти (ліцензовані, вже в збірці) | `assets/fonts/` |
| скріншоти для сторінки | робити з релізної збірки, не з дев |

## 1 · Основа

```css
--bg:            #0a0c14;   /* сторінка. Точний колір вікна застосунку */
--ink:           #e0dde8;   /* основний текст */
--muted:         rgba(255,255,255,0.28);
```

`#0a0c14` — не «майже чорний», а конкретний синювато-чорний. Він заданий у
трьох місцях застосунку однаково (`QColor(10,12,20)`, `setBackgroundColor
("#0a0c14")`, `body{background:#0a0c14}`), тож на сайті має бути саме він.

**Фон-сцена.** `Wireframecode - Final.html` — це та сама сторінка, що працює
фоном хабу. Вона вже містить дві шумові текстури (SVG `feTurbulence`,
плитки 180px і 260px) і пульсуючий віньєт по бортах:

```css
box-shadow: inset 0 0 26px 28px rgba(0,0,0,0.09);   /* базовий */
box-shadow: inset 0 0 40px 56px rgba(0,0,0,0.13);   /* шар пульсації, 12s */
```

Сторінку можна вставити як фон під контент — вона це вже вміє, бо саме так
працює в застосунку. Гейт `?doladu=splash` вмикає блок із логотипом; для
сайту він **не** потрібен.

## 2 · Скло (glassmorphism) — головний елемент

У застосунку дві реалізації однієї картки: Qt і HTML. Для сайту беріть HTML —
вона й є оригіналом.

```css
.card {
  border-radius: 12px;
  background: linear-gradient(to bottom,
      rgba(10,10,14,0.40)   0%,
      rgba(10,10,14,0.70)  10%,
      rgba(10,10,14,0.70) 100%);
  border: 1px solid rgba(255,255,255,0.06);
  box-shadow:
      inset 0  1px 0 rgba(255,255,255,0.14),   /* світло по верхньому краю */
      inset 0 -1px 0 rgba(255,255,255,0.05),
      0 8px 22px rgba(0,0,0,0.22);             /* м'яка тінь вниз */
  backdrop-filter: blur(12px);
}
```

**Три речі, які роблять це склом, а не просто темним прямокутником:**

1. **Градієнт зверху вниз**, а не рівна заливка — верх на 30% прозоріший.
2. **Внутрішня світла лінія по верхньому краю** (`inset 0 1px 0 rgba
   (255,255,255,0.14)`). Саме вона читається як заломлення на грані.
3. **Розмиття тла** — але помірне, 12px. Сильніше з'їдає фон-сцену, заради
   якої все й робилось.

Радіус **12px** для карток і **8px** для кнопок. Третього радіуса в
застосунку немає — не додавайте.

> ⚠ **Обережно з градієнтом і бордером разом.** У проєкті вже був баг:
> градієнт повторюється в область border-box і дає яскраву смугу по краю.
> Якщо треба кільце — робіть його зовнішнім `box-shadow`, а не бордером
> поверх градієнта.

## 3 · Кольори станів

Це не палітра «для краси» — кожен колір означає конкретний стан і вживається
в застосунку сотні разів. На сторінці вони мають означати те саме.

| колір | значення | де в застосунку |
|---|---|---|
| `#44CC88` | усе гаразд, перевірка пройдена | 184 вживання |
| `#F7D53E` | попередження, варто глянути | 257 |
| `#FF5555` | помилка, дія потрібна | 167 |
| `#A3CBF5` | інформація, дані, нейтральні числа | 202 |
| `#6958CC` | основний акцент продукту, вкладка Project | 88 |

**Акценти вкладок** — ними підписані заголовки розділів:

| вкладка | акцент |
|---|---|
| Project | `#6958CC` фіолетово-індиговий |
| UE5 | `#19D4A0` бірюзовий |
| LookDev | `#D6B92E` приглушене золото |
| VFX | `#FF9A5A` теплий помаранчевий |
| Inspector / дані | `#A3CBF5` |

Додатковий акцент `#40DED3` вживається в градієнтах смуг прокрутки:

```css
background: linear-gradient(to bottom,
    rgba(91,69,200,0.85), rgba(64,222,211,0.85));
border-radius: 999px;
```

## 4 · Кнопки

У застосунку **шість** нормалізованих кольорів кнопок, і будь-який акцент
зводиться до одного з них. Це зроблено навмисно: інакше вкладки
перетворюються на веселку.

```
indigo   #2b61b3      green    #63ab44      yellow   #d49f2c
orange   #d45f35      plum     #62477d      graypink #a77c96
```

**Три рівні.** Різницю дає **прозорість, а не насиченість** — це записано в
коді як правило:

> *«Deliberately RESTRAINED: a flat wash of the accent, no gradient, muted
> text — a full gradient fill turned every tab into a rainbow of solid
> buttons. The tier reads through opacity, not through colour volume.»*

```css
/* primary — головна дія картки */
.btn-primary {
  height: 32px;  border-radius: 8px;  padding: 0 12px;
  background: rgba(R,G,B,0.10);
  border:     1px solid rgba(R,G,B,0.34);
  color:      rgba(255,255,255,0.60);
  font: 600 10px 'JetBrains Mono','Consolas';
  letter-spacing: 1px;
}
.btn-primary:hover  { background: rgba(R,G,B,0.18);
                      border-color: rgba(R,G,B,0.50);
                      color: rgba(255,255,255,0.86); }
.btn-primary:active { background: rgba(R,G,B,0.26);
                      border-color: rgba(R,G,B,0.66); }
.btn-primary:disabled { background: rgba(255,255,255,0.02);
                        color: rgba(255,255,255,0.14);
                        border-color: rgba(255,255,255,0.05); }
```

Для сайту достатньо **двох**: `primary` (індиго) для «Купити» і `ghost` для
другорядного. `danger` на сторінці не потрібен.

**Кнопка «Портал» на головній** — це `primary` в індиго. Не робіть її
яскравішою за решту: вона й так єдина кольорова пляма на першому екрані.

## 5 · Типографіка

Чотири родини, кожна зі своєю роллю. Усі вже лежать у `assets/fonts/` і
ліцензовані для вбудовування.

| роль | родина | вага / розмір / трекінг |
|---|---|---|
| хром, заголовки островів | Space Grotesk | 700 · 14px · 0.35 |
| вкладки | Space Grotesk | 700 · 14px · 0.05 |
| заголовки карток | Azeret Mono | 700 · 14px · 0.4 |
| підписи розділів | Azeret Mono | 800 · 9px · **3px** |
| дані, числа, шляхи | JetBrains Mono | 500 · 9–11px · 0.2 |
| чіпи-фільтри | JetBrains Mono | 800 · 10px · 1.0 |
| основний текст | Inter | 400 · 13px · 0 |

**Заголовок звіту** — 20px / 800 / 0.4px, Azeret Mono.
**Підзаголовок під ним** — 11px, `--muted`, трекінг 0.5px.

Ключова риса стилю: **дуже широкий трекінг на дрібних підписах** (3px на
9-піксельному тексті). Саме він дає впізнаваний «технічний» вигляд. Не
зменшуйте його на сайті заради «читабельності» — на 9px це підпис, а не
текст для читання.

```css
@font-face { font-family:'Space Grotesk';
             src:url('fonts/SpaceGrotesk-Bold.ttf'); font-weight:700; }
/* так само: JetBrainsMono-*, Inter-*, AzeretMono-* */
```

> Вантажте шрифти **зі свого домену**, не з Google Fonts. Сторінка EULA це
> вже робить свідомо: підвантаження з CDN віддає IP відвідувача третій
> стороні, і для сайту в ЄС це зайве питання про згоду.

## 6 · Секція звіту — впізнаваний блок

Якщо хочете показати «як це виглядає» без скріншота, відтворіть цей блок:
у застосунку кожен інструмент друкує саме його.

```css
.sec        { border-radius: 12px; overflow: hidden;
              background: rgba(8,8,10,0.70);
              border: 1px solid rgba(255,255,255,0.07); }
.sec-title  { font: 800 9px 'Azeret Mono'; letter-spacing: 3px;
              padding: 7px 10px 6px;
              border-radius: 12px 12px 0 0;
              border-left: 3px solid var(--accent); }  /* колір розділу */
.sep        { height:1px; background: rgba(255,255,255,0.05);
              margin: 0 10px 6px; }
.row        { display:flex; justify-content:space-between;
              padding: 4px 10px; font-size: 11px; }
.row .k     { color: rgba(255,255,255,0.55); }
.row .v     { font-family:'JetBrains Mono'; color: var(--ink); }
```

Підпис розділу — **завжди капсом, з трекінгом 3px**, і зліва в нього
впирається кольорова смуга акценту розділу. Це найвпізнаваніша деталь
інтерфейсу.

## 7 · Що робити і чого не робити

**Робити:**

- Один фон на всю сторінку — `Wireframecode`, без повторів і без другої сцени.
- Скло тільки на картках. Текст поверх фону — прямо, без підкладки.
- Скріншоти в рамці з тим самим радіусом 12px і тією ж рамкою
  `1px rgba(255,255,255,0.06)`.
- Кольори станів у підписах до скріншотів: якщо показуєте попередження —
  підпишіть його `#F7D53E`, а не червоним.

**Не робити:**

- Не додавати нових акцентних кольорів. Їх у застосунку п'ять плюс чотири
  вкладкових — цього більше ніж досить.
- Не робити скло світлішим «щоб краще читалось». Верхній край уже світлий,
  цього достатньо; підняття підкладки вбиває фон.
- Не міняти радіуси. 12 і 8, і все.
- Не робити анімацій, крім тих, що вже є у фон-сцені. Продукт статичний і
  щільний; рух на сторінці читатиметься як інша річ.

## 8 · Структура сторінки-порталу — пропозиція

Порядок за тим, що покупець питає в такій послідовності:

1. **Що це.** Один екран: лого, один рядок про суть, кнопка «Спробувати».
2. **Як це виглядає.** 3–4 скріншоти, кожен із підписом на один рядок.
   Скріншоти — з релізної збірки, у 1× масштабі, без обрізки вікна.
3. **Що воно вміє.** Не список 139 дій. Чотири-п'ять груп із прикладом
   результату в кожній.
4. **Кому це.** Один абзац. 3D-художник, який здає роботу і хоче, щоб
   вона пройшла перевірку з першого разу.
5. **Скільки і як.** Ціна, пробний період, що саме дає ключ, посилання на
   Lemon Squeezy, посилання на EULA.

Внизу — те, що вже опубліковано:

## 9 · Чого в цьому документі свідомо немає

**Точних розмірів і відступів сітки сторінки.** Застосунок — це щільний
десктопний інтерфейс, сайт — ні. Переносити його відступи один в один буде
помилкою: те, що правильно для панелі 300px, задушить сторінку на 1440px.
Беріть звідси **мову** — кольори, скло, типографіку, радіуси — а ритм
сторінки будуйте окремо.

**Мобільної версії.** Продукт десктопний, і сторінка теж переважно
десктопна. Але вона мусить лишатись читабельною на телефоні, бо посилання
шлють у месенджерах: одна колонка, скріншоти на всю ширину з
горизонтальним скролом усередині власного контейнера.
